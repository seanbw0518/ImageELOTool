## Image ELO Comparison Tool

### An ELO-style tournament to compare and select favorite images from a collection. This was made to pick out my favorite photos every year.

1. (Optional) Define image name regex in a "`image_name_regex.txt`" file. This will determine which images the program is allowed to select. By default, all images will be opened.
2. Run `run Main.cmd` to start the program.
3. Open a folder containing a set of image or open a saved `json` file.
4. Click either the left or right image on screen to choose your favorite of the pair. Your decision updates each image's score (as seen in the table at the bottom of the screen).
5. Click the `X` button to remove that image entirely.
6. When you're done, you can save your progress.

- When an image's score drops too low, it will be eliminated and not shown again.
- Double click the images in the table to open them.
